# AGENTS.md

## Purpose

This repository is dedicated to AWS Certified Advanced Networking - Specialty (ANS-C01) exam preparation.

## Communication

- Respond in Japanese by default.
- Explain why an option is correct and why plausible alternatives are incorrect.
- Connect AWS services to networking fundamentals such as routing, BGP, DNS, TCP/IP, and security.

## Scope

Prioritize:

- Hybrid connectivity
- Direct Connect and Site-to-Site VPN
- Transit Gateway and multi-VPC connectivity
- Route 53 and hybrid DNS
- Load balancing, CloudFront, and Global Accelerator
- VPC networking, PrivateLink, and VPC endpoints
- Network monitoring and troubleshooting
- Network security and governance
- Automation and multi-account networking

## Documentation Rules

- Organize learning material according to the ANS-C01 exam domains.
- Include requirements, design choices, trade-offs, failure modes, and troubleshooting points.
- Use comparison tables and diagrams where useful.
- Clearly distinguish exam-focused explanations from production implementation guidance.
- Do not copy the entire `aws-reference` repository. Rework only the material needed for ANS-C01.

## Security

Never store secrets, credentials, private keys, account IDs, or sensitive evidence in this repository.
